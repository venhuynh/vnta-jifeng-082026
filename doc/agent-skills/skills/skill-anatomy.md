# Skill Anatomy

Use this as the local reference for how a skill folder should look.

## Structure

```text
skill-name/
  SKILL.md
  references/
  scripts/
  assets/
```

## Required File

`SKILL.md` must include:

- YAML frontmatter with `name` and `description`
- A concise body with the workflow or guidance

## Good Practice

- Keep `SKILL.md` lean
- Put detailed reference material in `references/`
- Add `scripts/` only when the skill needs runnable helpers
- Add `assets/` only when the skill ships output files or templates
