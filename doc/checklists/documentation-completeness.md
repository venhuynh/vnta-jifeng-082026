# Checklist Độ Đầy Đủ Tài Liệu

Dùng khi rà soát bộ tài liệu dự án.

## Bắt buộc có

- [ ] Tổng quan dự án.
- [ ] Kiến trúc dự án.
- [ ] Bản đồ source.
- [ ] Quy tắc code.
- [ ] Quy tắc database.
- [ ] Quy tắc Blazor DevExpress.
- [ ] Quy tắc validation input DevExpress toàn ứng dụng.
- [ ] Quy tắc nghiệp vụ HRM.
- [ ] Quy tắc sprint.
- [ ] Nhật ký triển khai.
- [ ] Template đặc tả chức năng.
- [ ] Template triển khai màn hình mới.
- [ ] Tài liệu chuẩn logic xử lý dữ liệu cho màn danh sách nghiệp vụ.
- [ ] Checklist popup mở từ màn hình UI chính.
- [ ] Checklist popup xác nhận trước khi hành động.
- [ ] Template ADR.
- [ ] Checklist hoàn tất.

## Nên có khi dự án lớn hơn

- [ ] ADR thật cho các quyết định kiến trúc.
- [ ] Tài liệu phân quyền.
- [ ] Tài liệu workflow nghiệp vụ.
- [ ] Tài liệu triển khai môi trường staging/production.
- [ ] Tài liệu backup/restore database.
